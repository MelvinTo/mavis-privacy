Mavis in use

Mavis follows and directs the AI coding agents (Claude Code, Codex, opencode) that run under herdr on your own computer, over SSH. This two-minute tour on an iPad shows:

Adding a server (host, user and the app's own key) · agents' chats with code, tables and images · a message sent · a question answered from its card · a reply's HTML page · ⌘K to switch agents · a permission prompt and the release notes it names · a new agent started and greeted. The agents in it are simulated.
